# Stellar Wallet Connect (React component style)

Bu repo, gönderdiğin React örneğindeki desenle (`useAccount`, `useIsMounted`, `ConnectButton`, `WalletData`) Freighter bağlama akışı içerir.

## Eklenen yapı

- `src/hooks/index.js`: `useIsMounted` ve Freighter testnet doğrulamalı `useAccount`
- `src/components/atoms/ConnectButton.jsx`: bağlan butonu
- `src/components/molecules/WalletData/index.jsx`: paylaştığın yapıya uygun wallet gösterimi

## Not

Bu kod, React proje iskeletine (`src/`) yerleştirildi. Mevcut projeye Vite/CRA kurulumu eklenerek doğrudan çalıştırılabilir.
